# 基于数字孪生的废塑料热解炼油智能工厂教学系统

本地在线课程原型：**泵电流监测单元的数字孪生构建与告警验证**。面向本科三、四年级，采用配置与验证方式，2学时90分钟。四个核心知识：对象映射、字段与单位、事件时间与发布周期、持续条件与滞回。

## v2.2.1 引导可用性修复

观察步骤增加实时操作清单、输入框/保存按钮定位、缺失操作提示和本轮保存反馈；重复仿真后保存最新有效观察也能继续。滚动高亮取消动画滞后，按可视区域及内部滚动容器重新定位，目标出屏时保留引导并提示返回。窄窗口预留气泡空间，保存按钮可完整显示。保留原有11步进度和正式记录，刷新后可从“操作引导”续接已保存的演练。

## v2.2 三维工厂工作区

三维工作区以16∶9为主要比例，仿真工具栏、内部层级树、画面和设备定位整合为一个窗口，支持窄屏抽屉、更多操作与全屏。工厂、区域、车间、设备四级导航与路径同步；程序化示意模型支持实例内改名、归属调整、显隐和隔离。结构调整暂停仿真并要求复验，提交冻结场景快照；旧v2默认场景与提交指纹继续兼容。

## v2.1 操作引导与师生端

首次使用可选择约5分钟高亮演练，实际完成配置、预测、仿真、调试、观察与演练提交。演练使用独立会话和存储，不影响正式数据，也不进入教师端。页眉随时可重看，支持返回、退出和重新演练。

左侧显示课程建设状态和个人证据进度，右侧持续显示实验目的、核心知识、观察重点和成果要求。主按钮统一为“开始仿真”；一个实验内可以开展多轮仿真。

学生端正式提交后生成冻结报告，教师端演示按版本查看证据和录入30分论证评价。修改草稿不影响提交副本；新版本另行批阅，历史反馈保留。当前仅是同一浏览器的本地角色演示，没有真实账号权限隔离或跨设备同步。

## 启动

双击start.cmd，保持服务打开，在Chrome或Edge访问 http://127.0.0.1:5173/ 。依赖和生产构建已提供，也可执行 `node serve.mjs`。需要Node.js 22.12或更新兼容版本。服务仅监听本机。

开发：`npm ci` 后 `npm run dev`。验证：`npm test`、`npm run build`。构建包含TypeScript检查；生产文件在dist，不能直接双击dist/index.html。

## 完成实验

1. 先配置台账、三维绑定和泵测点，再保存预测。配置正确本身不得结果分。
2. 关联实验：只改变泵模型绑定，运行并点选三维泵、保存观察，修复后再运行、观察；随后只改变泵字段，重复错误和修复对照。
3. 周期实验：以其他配置完全相同的1秒、3秒发布周期，各运行完整40秒并保存观察。
4. 策略实验：参数相同，分别采用即时、持续、持续加滞回策略，运行并观察；比较源检测输出。有效滞回事件需确认和恢复后关闭。
5. 领取迁移任务，保留新编码并独立修复，再运行、观察。
6. 在报告按编号引用实测结果，填写结论与边界，提交教师复核。30分论证分由教师明确录入，不由字数决定。

每轮从固定1—40秒输入重放。可以逐秒或快捷至终点；快捷执行同样计算每个样本。历史快照保留；修改配置后显示待复验。记录的学习达成用于教学对照，不代替当前配置验收。

## 数据和实现边界

数据版本pump-labelled-40s-v2.0。包含正常、2秒尖峰、持续越限、阈值附近波动及恢复。11—34秒为教学标注事件，非真实故障诊断。模型和数据自建，未读取企业资料，不连接PLC/DCS等现场设备，没有工艺耦合或真实网络延迟模型。

三维读数及状态按模型绑定的实际资产显示。未绑定无数据，错误字段显示真实源单位和无效质量，不送入有效电流告警。源检测器每秒执行，发布周期仅影响可见点，事件处置不阻断后续检测。

v2进度保存在独立localStorage键；v1存档保留只读，可导出原始JSON，不转换旧成绩。刷新、页面切换和导入后暂停，不补算离线时间。导入逐字段校验，源数据和检测结果按快照重算，错误文件不覆盖当前进度。手工试验记录最多支持1000轮、备份文件20MB，请定期导出并保持合理试验数量。

课程是浏览器单人应用。教师录分无身份隔离，浏览器记录可被使用者修改；导入重算不构成防作弊保证。正式教学服务须增加认证、服务端评价、实例隔离和平台接口。本地原理提示未接入大模型。
